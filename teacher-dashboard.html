لوحة تحكم المعلم الشاملة (El Husseiny Platform)

إدارة مستقلة: طلاب السنتر، حصص الأونلاين، وحصص الزوار (باشتراك منفصل 50 ج للمشاهدة)

معاينة صفحة الطالب

1. تسجيل طالب سنتر جديد (بيانات أساسية وتوليد ID تلقائي)

تسجيل بيانات حضور السنتر وتوليد ID خاص به تلقائياً. (اشتراك مشاهدة الأونلاين 50 ج اختياري ومنفصل لمن يرغب).

إدارة السنتر 🏢

2. نظام التحكم المستقل للحصص (حسب تصنيف الجمهور)

تحكم منفصل لكل قسم في: اسم الحصة، العنوان، الصف، الجروب، رفع الملفات والصور، وصلاحيات المشاهدة

لوحة شرف أوائل الطلاب (أفضل 5 طلاب بكل صف ومجموعة)

يتم ترتيب الطلاب تلقائياً بناءً على الدرجات (الامتحان الورقي + السمايع) للتحفيز والتكريم المستمر.

3. سجلات الطلاب (الحفظ السحابي التلقائي والتحكم باشتراك الـ 50 ج)

4. جدول متابعة حضور ودرجات الطلاب (حفظ فوري)
